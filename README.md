**U-Bot** — это личный инструмент, который я разработал для автоматизации рутины. Он позволяет подключать Telegram-каналы (публичные и приватные), создавать и планировать публикации (текст, фото, видео, опросы), а также следить за состоянием домашнего сервера.

> **Важно:** Проект является моей личной разработкой. Копирование и распространение кода без моего разрешения запрещено.

## ✨ Основные возможности

- **Управление каналами:** Добавление, проверка прав, удаление из управления.
- **Создание контента:** Текст, медиа, альбомы, опросы и inline-кнопки.
- **Планировщик:** Отложенные публикации с предуведомлениями и защитой от дублей.
- **Напоминания:** Разовые и повторяющиеся.
- **Мониторинг сервера:** Просмотр CPU, RAM, диска и управление питанием.
- **Резервное копирование:** Создание и управление бэкапами базы данных.

## 🚀 Быстрый старт

1. Клонируй репозиторий:
    git clone https://github.com/SK3PS15/U-Bot.git
    cd U-Bot

2. Запусти установщик и следуй инструкциям в терминале:
    sudo bash install.sh
